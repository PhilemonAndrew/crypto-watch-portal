# Crypto Watch Portal

## 📖 Project Overview
The **Crypto Watch Portal** is a React-based cryptocurrency tracking application. It provides real-time market data through a clean, responsive, and user-friendly interface. This project demonstrates front-end development skills in building dynamic dashboards, handling live data, and designing modern web applications.

---

## ✨ Features
- **Real-time cryptocurrency market data** displayed in an intuitive dashboard.
- **Responsive design** for seamless use across desktop and mobile devices.
- **Reusable React components** for modular and maintainable code.
- **Clean and modern UI** focused on usability and clarity.

---

## 🛠️ Technologies Used
- **React** – component-based front-end framework.
- **JavaScript (ES6+)** – core programming language.
- **CSS** – styling and layout.
- **Vite** – fast build tool and development server.

---

## ⚙️ Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/PhilemonAndrew/crypto-watch-portal.git
   cd crypto-watch-portal
2. Install dependencies
   npm install
3. Start the development server:
   npm run dev

🚀 Usage
  Run the development server and open the provided local URL in your browser.

  Explore the dashboard to view live cryptocurrency market data.

  Extend or customize components in the src directory to add new features or improve functionality.  

  PROJECT STRUCTURE
  crypto-watch-portal/
└── src/
    ├── assets/        # Static files (images, icons, etc.)
    ├── App.css        # Global styles for the app
    ├── App.jsx        # Root React component
    ├── index.css      # Base styling (applied globally)
    └── main.jsx       # Application entry point

 🔑 Implementation Details
.main.jsx: Bootstraps the React application and mounts it to the DOM.

.App.jsx: Central component where the cryptocurrency tracking UI and logic are defined.

 .Styling: Split between App.css (component-specific) and index.css (global).

.Assets: Organized in a dedicated folder for easy management of static resources.
